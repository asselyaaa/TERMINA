ABOUT THE PROJECT

Why TERMINA?

A trilingual IT glossary created with the support of AI tools and verified online sources.

01 — PURPOSE

Making IT terminology easier to understand.

TERMINA is a thematic glossary focused on Information Technology terminology. The project presents terms in three languages: English, Kazakh and Russian.

Each entry contains a translation, a short definition and a contextual example.

02 — AI ASSISTANCE

Artificial intelligence as a research assistant.

AI tools were used during the preparation of the glossary to help generate initial translations, definitions and contextual examples.

AI-generated content was reviewed and edited before being included in the final glossary.

03 — VERIFICATION

Human review and reliable sources.

The terminology was checked against authoritative IT and cybersecurity reference materials.

The final website combines AI-assisted drafting with human editing and source verification.

04 — TECHNOLOGY

A simple web-based solution.

The website was developed using HTML, CSS and JavaScript and published using GitHub Pages.

JavaScript provides the search and category filtering functionality.
